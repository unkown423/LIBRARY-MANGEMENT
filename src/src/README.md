# Library Management System

This is a Library Management System developed using Python and MySQL.

## Features

- Add Book
- Issue Book
- Return Book
- Delete Book
- Display Books
- Issued Books Report
- Returned Books Report

## Technologies Used

- Python
- MySQL
- MySQL Connector

## Files

### library_management.py

Contains the complete Python program.

### library_app.sql

Contains the MySQL database and table creation commands.

### Library_Management_Project.pdf

Contains the complete project documentation.

## Database

Database Name:

library_app

Tables:

- books
- issue
- return_

## How to Run

First install MySQL.

Then install the Python MySQL connector:

pip install mysql-connector-python

Create the database using:

library_app.sql

Then open:

library_management.py

Enter your MySQL username and password.

Run:

python library_management.py
